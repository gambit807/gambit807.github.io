Independent travel technology project

Track selected hotel prices without repeatedly searching by hand.

Hotel Price Watch is a pilot service for monitoring specific hotels, stay dates and booking conditions. It records comparable offers over time and can alert a traveler when a meaningful price opportunity appears.

Pilot in development

Focused monitoring

Travelers choose the exact hotels, dates, occupancy and conditions they care about rather than searching an entire destination.

Comparable rates

The system is designed to compare like-for-like offers, including meal plan, cancellation policy and total stay price.

Provider checkout

Hotel Price Watch does not take bookings or payments. When an eligible provider integration returns an offer, the traveler is directed to the provider to review and complete the booking.

About the project

Hotel Price Watch is a small independent software project being developed to reduce repetitive hotel-price checking for travelers. The current pilot is designed for a limited set of selected properties and dates, with a technical architecture that can support additional hotels through configuration rather than custom code.

Where an official travel-provider API is available and approved for use, the project is intended to use that API for availability, rates and provider landing links. The project does not scrape provider websites as its intended production integration method.

Independence notice: Hotel Price Watch is not currently affiliated with, endorsed by, or operated by Agoda. Any future Agoda integration would only be enabled after official partner approval and according to Agoda's applicable API and affiliate terms.
