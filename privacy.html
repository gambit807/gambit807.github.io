Privacy

Last updated: August 16, 2026

Website visitors

This public informational website does not contain an account system, booking form, payment form or newsletter signup. The project does not intentionally collect personal information from visitors through this website.

Price monitoring

The pilot service is designed to store hotel-monitoring configuration such as property identifiers, stay dates, occupancy and booking criteria, together with price-history data returned by approved provider integrations. It is not designed to store payment-card data or complete hotel bookings itself.

Third-party providers

If a traveler follows a link to a hotel or travel provider, that provider's own privacy policy, terms and data practices apply on the provider's website or application.

Infrastructure

The project currently uses GitHub for source-code hosting and automation. GitHub may process standard technical data associated with access to GitHub-hosted pages according to GitHub's own policies.

Contact

Questions about this project can be directed to the project owner through GitHub.
